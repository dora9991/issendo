# いっせんどう — 画像生成の共通ルール（Codex 用）

小学1年生がどハマりする横スクロール剣アクション「いっせんどう」の絵を作る。
ゲーム本体は Canvas で動かす。ここで作るのは **敵キャラの一枚絵** と **ステージ背景**。

## 絵柄（全画像で統一・凍結）
- 日本の子ども向けスマホゲームのイラスト。**かわいくて かっこいい**（かっこかわいい）。
- 2〜3頭身のデフォルメ、大きくてキラッとした目（ハイライト2つ）、表情がはっきり分かる顔。
- **太めの濃い紫の輪郭線（#3a2a5e くらい）**、フラットなセル塗り＋やわらかいグラデーションのハイライト。ステッカーのような、はっきりした見た目。
- 明るく彩度の高い色。背景と重ねても埋もれない。
- 6歳が見て安心できること：**血・グロ・リアルなホラー・残酷な武器表現は禁止**。悪役は「いたずらっぽい／強そう」くらい。
- **画像の中に文字・数字・ロゴ・透かし・サインを入れない。**
- 既存のゲームやアニメのキャラクターに似せない（完全オリジナル）。

## 敵キャラ（kind = enemy）
- **透明背景（アルファ付きPNG）・1体だけ・全身・床の影なし・切れていない。**
- **体の正面は画面の左を向く**（プレイヤーは画面の左にいる）。横〜3/4ビュー。
- 小さく表示しても何者か分かる、強いシルエット。細い飾りを増やしすぎない。
- ボス（boss=true）は一回り豪華に：王冠・オーラ・大きな武器など。でも絵柄は同じ。

## 背景（kind = bg）
- **横長 16:9、人物・キャラクターは描かない**（キャラは上にゲームが描く）。
- 横から見た2Dアクションゲームのステージ。**画面の下 約27% は、まっすぐ横に続く平らな道（地面）**。
  道の上のふち（キャラの足が乗る線）は **画像の高さの約73% の位置で、まっすぐ水平**。
- 道の部分と、道のすぐ上（高さ45〜73%あたり＝キャラが立つ所の後ろ）は、ごちゃごちゃさせず、少しおだやかなコントラストにする（キャラが目立つように）。見どころは上の方と左右のはしに。
- 道の上にはボタンが重なるので、道には大きな物を置かない（模様・草・石くらい）。

## 手順
1. 渡されたIDごとに、組み込みの画像生成機能で画像を作る。
2. 失敗（不透明な背景〈enemyのみ〉・文字が入った・切れている・2体以上・右を向いている・怖すぎる）は捨てて作り直す（最大2回）。
3. できたPNGを処理する：
   - enemy: `python3 art-work/process.py enemy <生成PNGのパス> <ID>` → `img/enemy/<ID>.webp`
   - bg:    `python3 art-work/process.py bg <生成PNGのパス> <ID>` → `img/bg/<ID>.webp`
   - ui:    `python3 art-work/process.py ui <生成PNGのパス> <ID>` → `img/ui/<ID>.webp`（透明背景・主人公など）
   （生成PNGの元ファイルは `art-work/raw/<ID>.png` にもコピーしておく）
4. このバッチの画像をまとめて `python3 art-work/sheet.py <バッチ名> <ID...>` でコンタクトシートにし、目で見比べる。絵柄がそろっていない・品質が低いものは作り直す。
5. `art-work/ledger/<バッチ名>.md` に「ID／ねらい／完了・未完（理由）」を書く。

## 守ること
- 作成・編集してよいのは `art-work/raw/` `art-work/ledger/` `art-work/sheets/` `img/enemy/` `img/bg/` `img/ui/` だけ。
  **ソースコード（.html / .js / .css）やその他のファイルは編集禁止。**
- 別のバッチが同じフォルダに並行して書き込む。**自分のバッチのIDのファイルだけ**を作る・消す。
- 計画だけで終わらせず、渡された全IDの画像を完成させる。
