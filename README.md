# いっせんどう（issendo）

しょうがく1ねんせい むけの よこスクロール けん アクション。ぜんぶ ひらがな・わかちがき。
iPhone の よこがめん プレイむけ（パソコン でも あそべる）。

あそぶ: https://dora9991.github.io/issendo/

## あそびかた

- **タイトル** → がめん を たっぷ →「つづき から」/「はじめる」
- **メニュー**
  - 🗡️ すぶり … がめん を れんだ（15かい で ぼーなす ×2）→ こうげき アップ
  - 👟 はしりこみ … たっぷ で じゃんぷ（3かい とべたら ぼーなす ×2）→ たいりょく アップ
    - とっくん の こうか は、たおした てき 4たい ごと に ふえる（×1〜×6）
  - ✨ わざ … おかね で わざ を おぼえる（おなじ なかま は いちばん つよい もの だけ ボタン に でる）
  - 📖 ずかん … たおした てき の カード と ★
  - 🔥 たたかう … 5つ の すてーじ × 4たい（4たいめ は ぼす）。カード に「よゆう／かてそう／ぎりぎり／きけん」
- **バトル**
  - ◀ ▶ うごく ／ きる！ ／ わざ ボタン ／ **ひっさつ**（ゲージ が たまったら カットイン つき の いっせん）
  - てき の あたま に「！」が でたら こうげき の あいず。さがる と よけられる
  - こうげき が あがる と けん が しんか（きのけん → てつ → はがね → ほのお → いかずち → にじいろ）
- パソコン: ← → うごく ／ Z きる ／ X ひっさつ ／ すうじ わざ ／ ↑ そらがけ ／ Esc ていし

## ほぞん

localStorage に じどうほぞん（キー `issendo_save_v3`。v3 の きろく は そのまま ひきつげる）。
「はじめ から」や「よみこむ」の まえ の きろく は `issendo_save_v3_bak` に ひかえ を とる（せってい → まえ の きろく に もどす）。
せってい → きろく を かきだす／よみこむ で JSON バックアップ。
