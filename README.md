# いっせんどう（issendo）

しょうがく1ねんせい むけの アクションゲーム。ぜんぶ ひらがな・わかちがき。
iPhone の よこがめん プレイむけ。

## あそびかた

- **タイトル** →「はじめる」または「つづき から」
- **メニュー** … ステータスかくにん／すぶり／はしりこみ／わざを かう／たたかう
  - すぶり … こうげき ＋1
  - はしりこみ … たいりょく ＋3
  - わざを かう … ひっさつわざ を こうにゅう（もっている／かえる！／たりない を いろで くべつ）
  - たたかう … てき 20たい から えらぶ
- **バトル** … よこ ぜんめん。ひだりした に ◀▶、みぎした に「きる！」と ひっさつわざ ボタン
  - パソコン … ← → うごく／Z きる／すうじキー で わざ

## ほぞん

きろくは ブラウザの localStorage に じどうほぞん。
メニューの「きろくを かきだす／よみこむ」で JSON ファイルに バックアップ できる。
