# いっせんどう（issendo）

しょうがく1ねんせい むけの よこスクロール けん アクション。ぜんぶ ひらがな・わかちがき。
iPhone の よこがめん プレイむけ（パソコン でも あそべる）。

あそぶ: https://dora9991.github.io/issendo/

## あそびかた

- **タイトル** → がめん を たっぷ →「つづき から」/「はじめる」
- **メニュー**
  - 🗡️ すぶり … がめん を れんだ（15かい で ぼーなす ×2）→ こうげき アップ
  - 👟 はしりこみ … たっぷ で じゃんぷ（3かい とべたら ぼーなす ×2）→ たいりょく アップ
    - とっくん の こうか は、たおした てき 4たい ごと に ふえる（×1〜×6）
  - ✨ わざ … おかね で わざ を おぼえる（おなじ なかま は いちばん つよい もの だけ ボタン に でる）
  - 📖 ずかん … たおした てき の カード と ★
  - 🔥 たたかう … 5つ の すてーじ × 4たい（4たいめ は ぼす。20たい たおす と うら の 5すてーじ）。カード に「よゆう／かてそう／ぎりぎり／きけん」
- **バトル**（みぎて の ボタン は 2つ だけ）
  - ◀ ▶ うごく ／ **きる！**（まわり の わっか が ひっさつ ゲージ。にじいろ の「ひっさつ！」に なったら おす と カットイン つき の いっせん）
  - **わざ！** … その とき いちばん いい わざ を ゲーム が えらんで だす（たいりょく が すくない → いき、てき の「！」→ むてき など）。ひかって いる とき が おしどき
  - せってい の「ボタン を まとめる」を けす と、まえ の ならべかた（わざ が ばらばら・ひっさつ ボタン べつ）に もどる
  - てき の あたま に「！」が でたら こうげき の あいず。さがる と よけられる
  - こうげき が あがる と けん が しんか（きのけん → てつ → はがね → ほのお → いかずち → にじいろ → ほし → たいよう → りゅう → でんせつ）
- **うら の せかい** … 20たい たおす と ひらく。いろ の ちがう つよい てき 20たい（すてーじ 6〜10）と、あたらしい わざ 4つ（いき きわみ・そらおとし きわみ・かいしん の こころ・ひっさつ の こころ）
- とっくん の「はやおくり」は ぼーなす なし（れんだ・じゃんぷ で あそぶ ほう が よく そだつ）
- パソコン: ← → うごく ／ Z きる（にじいろ の とき は ひっさつ）／ C わざ ／ X ひっさつ ／ すうじ わざ（ばらばら の とき）／ Esc ていし

## つよさ の きめかた（2026-10-25 に みなおし）

- 「とっくん の かいすう」の よてい から てき の つよさ を きめた（20たいめ まで やく 660かい・40たいめ まで やく 2300かい）。
- 「よゆう／かてそう／ぎりぎり／きけん」は、じどう たいせん（`dev/sim.js`）で たしかめて あわせた。わざ は ひかえめ に かぞえる（じょうず に つかえない こ も いる ため）。
- たしかめかた：`index.html?mute=1`（おと を ださない・がめん を かくしても とまらない）を ひらいて、コンソール で `dev/sim.js` を よみこみ、`kidSim / sloppySim / matomeSim(てき番号, こうげき, たいりょく, わざ, かいすう)`。

## ほぞん

localStorage に じどうほぞん（キー `issendo_save_v3`。v3 の きろく は そのまま ひきつげる）。
「はじめ から」や「よみこむ」の まえ の きろく は `issendo_save_v3_bak` に ひかえ を とる（せってい → まえ の きろく に もどす）。
せってい → きろく を かきだす／よみこむ で JSON バックアップ。
